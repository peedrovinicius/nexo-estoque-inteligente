# Nexo Estoque

Plataforma web de gestão inteligente e auditável de estoque para farmácias, mercantis, lojas, depósitos e distribuidores.

O Nexo Estoque combina operação cotidiana, rastreabilidade e apoio à decisão. Além do cadastro e das movimentações, o projeto foi desenhado para antecipar ruptura, excesso e vencimento, registrar o motivo de cada recomendação e usar IA como camada explicativa sem entregar a ela o controle dos cálculos críticos.

## Stack
- Java 21 + Spring Boot
- React + TypeScript + Vite
- MySQL
- JDBC e CallableStatement
- Stored Procedures
- JUnit
- API REST

## Diferenciais
- controle por lote e validade
- estratégia FEFO
- inventário cego
- trilha de movimentações
- motor determinístico de simulação
- cenários "e se?" para demanda, atraso e reposição
- recomendações auditáveis
- camada de IA para explicar riscos e ações
- arquitetura preparada para múltiplos segmentos e filiais

## Estrutura
```text
backend/     API Java + Spring Boot
frontend/    interface React + TypeScript
database/    schema e Stored Procedures
```

## Demonstração
A primeira interface inclui login administrativo e dashboard demonstrativo. As credenciais públicas são exclusivamente para demonstração e serão substituídas por autenticação segura antes de qualquer uso real.
